Underscore-rich Python API
==========================

.. py:function:: function_name(argument)

   Return ``argument`` unchanged.

.. py:class:: Widget

   A representative class with a dunder method.

   .. py:method:: __init__(value)

      Initialize the widget.

.. py:class:: Payload__Envelope

   A class whose own name contains a double underscore.

These definitions can be revisited through :py:func:`function_name`,
:py:meth:`Widget.__init__`, and :py:class:`Payload__Envelope`.
